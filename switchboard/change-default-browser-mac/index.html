How to change the default browser on Mac

Three ways to do it, what to do when it doesn't stick, and how to get around the one-default-browser limit.

By Aditya Raj Singh · Updated 17 October 2026 · macOS 13 Ventura to macOS 26 Tahoe

Short answer: open the Apple menu, choose System Settings, click Desktop & Dock, scroll down and pick a browser from the Default web browser menu. On macOS 12 Monterey or earlier, it's under System Preferences → General.

1. Change it in System Settings (macOS Ventura 13 and later)

This works on macOS 13 Ventura, 14 Sonoma, 15 Sequoia and 26 Tahoe.

  1. Install the browser you want to use, and open it once.
  2. Open the Apple menu in the top-left corner and choose System Settings.
  3. Click Desktop & Dock in the sidebar.
  4. Scroll down on the right to Default web browser and pick your browser.

The change applies right away. Links you click in Mail, Messages, Slack, Notes and most other apps now open in that browser.

2. On macOS Monterey 12 and earlier

  1. Open the Apple menu and choose System Preferences.
  2. Click General.
  3. Pick your browser from the Default web browser menu.

These steps match Apple's own support article.

3. Change it from the browser itself

Most browsers can ask macOS to make them the default. macOS then shows a dialog asking you to confirm the change.

  • Chrome: Settings → Default browser → Make default.
  • Firefox: Settings → General → Make Default.
  • Brave and Edge: open Settings, search for "default browser", then click Make default.
  • Safari: Safari → Settings → General → Set Default.

4. Change it from Terminal

macOS has no built-in command for this. The open-source defaultbrowser tool fills the gap. Install it with Homebrew:

brew install defaultbrowser

Run defaultbrowser on its own to list installed browsers, then pass a name from that list, such as defaultbrowser chrome or defaultbrowser firefox, to switch. macOS still asks you to confirm, so this helps with setup scripts but can't run fully unattended.

5. When changing the default browser doesn't work

The browser isn't in the list

macOS lists only apps that have registered as web browsers. Move the browser into /Applications, open it once, then check again. If you launched it straight from its downloaded disk image, install it properly first.

The setting keeps changing back

Another browser is probably asking to become the default when it starts. Turn off its "check if this is the default browser" or "make default" prompt in that browser's settings, then set your choice again.

One app still opens links somewhere else

Some apps ignore the system default because they have their own link setting or a built-in viewer. Look for an "open links in" option in that app's settings.

6. What if you want more than one default browser?

macOS allows exactly one default browser. That gets in the way fast when you:

  • keep work and personal accounts in separate Chrome or Brave profiles
  • use Safari day to day but need Chrome for Google Meet or a web app
  • want links from Slack to open in your work profile, and links from Messages in your personal one

FAQ

Where is the default browser setting on macOS Sonoma, Sequoia or Tahoe?

System Settings → Desktop & Dock → Default web browser. Apple moved it there from General in macOS Ventura.

Can I make a specific Chrome profile the default?

Not with macOS alone. macOS picks the browser, and Chrome decides which profile window gets the link. A browser picker such as Switchboard can open links in a named profile.

Does changing the default browser change my default email app?

No. The default email app is a separate setting, inside the Mail app's settings under General.

Can I set a different default browser for each website?

Not natively. A browser picker with per-site rules does this. For example, send meet.google.com to Chrome and everything else to Safari.
