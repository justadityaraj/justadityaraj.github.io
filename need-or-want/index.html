Install in one line

Local only. No account, no network calls, no telemetry.

  1. Claude Code

    claude mcp add --scope user need-or-want -- npx -y need-or-want-mcp

  2. Claude Desktop

    { "mcpServers": { "need-or-want": {
  "command": “npx”, "args": ["-y", "need-or-want-mcp"] } } }

  3. Set your budget

    Tell Claude: “Set up Need or Want. My currency is USD and my monthly budget is 2000.”

  4. What it needs

    Node 22 or later. Your data stays in ~/.need-or-want/ on your machine.

Questions

What is Need or Want?

An open-source MCP server for Claude Code and Claude Desktop that checks a purchase before you make it. It asks a few fixed multiple-choice questions, scores the purchase from 0 to 100 and returns BUY, WAIT or SKIP, labelled NEED, MIXED or WANT.

How does it decide if something is a need or a want?

Three questions: what’s prompting the purchase, whether you already own something that does the job, and what would happen if you waited 30 days. Each answer has a fixed value. A weighted score of 0.70 or more is a need, under 0.35 is a want, and anything between is mixed.

Can I argue with the verdict?

Yes, but only facts move it. Changing the price, the category, what you own or what happens if you wait re-runs the score. A revised estimate of how often you’ll use it counts at 50%, once. Repeating yourself, saying you deserve it, or pointing at a sale changes nothing.

Does an AI decide the verdict?

No. The verdict is plain arithmetic in the server: the same inputs always give the same result. Claude only asks the questions and relays the answer.

Can I still buy something it says to skip?

Always. Buying anyway is logged as an override, then reviewed at 30 and 90 days like any other purchase, so you can see whether the verdict or the override was right.

Where is my data stored?

In ~/.need-or-want/ on your own machine. The server makes no network calls, needs no account and sends no telemetry.

Is it free?

Yes. It’s MIT-licensed and free, with the full source on GitHub.
